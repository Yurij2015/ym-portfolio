# Індексація сторінок послуг через Nuxt Studio

Для кожної мовної версії є поле **«Дозволити індексацію / Allow indexing»** (`indexable`).

- Вимкнено / `false`: robots meta і HTTP-заголовок X-Robots-Tag мають значення `noindex, follow`.
- Увімкнено / `true`: обидва мають значення `index, follow`.
- Якщо поле відсутнє, сторінка залишається `noindex`.

## Де змінювати

1. Відкрий Nuxt Studio на `/_studio` у запущеному сайті.
2. Вибери файл потрібної послуги, наприклад `content/uk/services/laravel-development.yml`.
3. У режимі форми ввімкни **Allow indexing** після перевірки тексту.
4. Збережи зміни. Для англійської та польської версій перемикач окремий.

Список послуг має власне налаштування:

- `content/uk/services.yml` — `/services`;
- `content/en/services.yml` — `/en/services`;
- `content/pl/services.yml` — `/pl/services`.

Налаштування списку не вмикає індексацію всіх послуг автоматично. Всі файли початково мають `indexable: false`.

## Збереження та публікація

У локальному dev-режимі Studio зберігає зміни у файли. Для продакшну потрібні налаштовані Git-репозиторій та авторизація Studio. Зміни стануть видимі на продакшні після публікації й нового деплою: сторінки кешуються через Vercel ISR. Збереження локального файлу саме по собі не змінює продакшн.

Публікація зі Studio може створювати Git-коміт. Не використовуй її до рішення опублікувати відповідний набір змін.

`index, follow` дозволяє індексацію, але не гарантує її та не змінює пошуковий індекс миттєво. Налаштування стосуються лише нового розділу послуг.
